# Database Rules

## Migration Conventions

### Naming

Migration filenames are auto-generated by Laravel (`YYYY_MM_DD_HHMMSS_description.php`). Ensure descriptions are clear:

```
2024_01_15_103000_create_users_table.php
2024_01_15_103001_create_password_reset_tokens_table.php
2024_02_01_080000_add_email_verified_at_to_users_table.php
2024_03_10_120000_create_orders_table.php
2024_03_15_090000_add_shipping_columns_to_orders_table.php
```

### Rules

- Always use `Schema::create()` for new tables
- Always include `created_at` and `updated_at` timestamps
- Use `foreignId()->constrained()` for foreign keys
- Index columns used in WHERE, JOIN, or ORDER BY
- Use `unsignedBigInteger` for foreign keys
- Use `nullable()` sparingly — prefer sensible defaults

```php
public function up(): void
{
    Schema::create('orders', function (Blueprint $table) {
        $table->id();
        $table->foreignId('user_id')
            ->constrained()
            ->cascadeOnDelete();
        $table->foreignId('product_id')
            ->constrained()
            ->restrictOnDelete();
        $table->unsignedInteger('quantity')->default(1);
        $table->unsignedBigInteger('subtotal_cents');
        $table->unsignedBigInteger('tax_cents')->default(0);
        $table->unsignedBigInteger('total_cents');
        $table->string('status', 20)->default(OrderStatus::Pending->value);
        $table->string('currency', 3)->default('USD');
        $table->string('notes', 500)->nullable();
        $table->softDeletes();
        $table->timestamps();

        $table->index(['user_id', 'status']);
        $table->index('created_at');
    });
}
```

## Soft Deletes

Use soft deletes on all resources that need recoverability:

```php
use Illuminate\Database\Eloquent\SoftDeletes;

class Order extends Model
{
    use SoftDeletes;

    // The SoftDeletes trait already casts deleted_at to a datetime — the old
    // $dates property was removed. If you need to be explicit, use casts():
    protected function casts(): array
    {
        return [
            'deleted_at' => 'datetime',
        ];
    }
}
```

- Tables with soft deletes include `$table->softDeletes()` in migration
- Use `withTrashed()`, `onlyTrashed()`, `restore()` methods for trashed records
- Always filter by soft delete state in queries (use model scopes like `active()`)

## Index Strategy

Add indexes proactively for columns used in:

- `WHERE` clauses (especially on foreign keys)
- `JOIN` conditions
- `ORDER BY` clauses
- `GROUP BY` clauses
- `DISTINCT` queries

```php
$table->foreignId('user_id')->constrained()->index();
$table->string('email')->unique();
$table->string('status', 20)->index();
$table->dateTime('shipped_at')->index();

// Composite index for common query patterns
$table->index(['user_id', 'status', 'created_at']);
```

### When NOT to Index

- Columns with very low cardinality (e.g., boolean flags used in < 5% of queries)
- Columns already covered by a unique constraint
- Columns used only in `SELECT` (not filtering or joining)

## Foreign Key Constraints

- Every foreign key must reference an existing table
- Use appropriate cascade behavior:
  - `cascadeOnDelete()` — for dependent records (e.g., order_items → orders)
  - `restrictOnDelete()` — for reference data (e.g., products → orders)
  - `nullOnDelete()` — for optional relationships
- Always define foreign keys in migrations, not just in models

```php
$table->foreignId('user_id')
    ->constrained('users')
    ->cascadeOnDelete();

$table->foreignId('product_id')
    ->constrained('products')
    ->restrictOnDelete();

$table->foreignId('parent_id')
    ->nullable()
    ->constrained('categories')
    ->nullOnDelete();
```

## Models

### Eloquent Model Rules

- Extend `Illuminate\Database\Eloquent\Model`
- Define `$fillable` or `$guarded` (prefer `$fillable`)
- Define relationships with typed returns
- Use `$casts` for type casting
- Use scopes for reusable query filters
- Use accessors for computed attributes

```php
class Product extends Model
{
    use HasFactory;

    protected $fillable = [
        'name',
        'slug',
        'description',
        'price_cents',
        'currency',
        'stock',
        'is_active',
        'category_id',
    ];

    protected function casts(): array
    {
        return [
            'price_cents' => 'integer',
            'stock' => 'integer',
            'is_active' => 'boolean',
            'category_id' => 'integer',
            'published_at' => 'datetime',
        ];
    }

    public function scopeActive(Builder $query): Builder
    {
        return $query->where('is_active', true)->where('stock', '>', 0);
    }

    public function category(): BelongsTo
    {
        return $this->belongsTo(Category::class);
    }

    public function reviews(): HasMany
    {
        return $this->hasMany(Review::class)->orderByDesc('created_at');
    }
}
```

## Seeders and Factories

### Factories

Use factories for test data and seeders:

```php
class OrderFactory extends Factory
{
    protected $model = Order::class;

    public function definition(): array
    {
        return [
            'user_id' => User::factory(),
            'status' => fake()->randomElement(OrderStatus::cases())->value,
            'subtotal_cents' => fake()->numberBetween(500, 50000),
            'tax_cents' => fake()->numberBetween(0, 5000),
            'total_cents' => fn (array $attributes) => $attributes['subtotal_cents'] + $attributes['tax_cents'],
            'currency' => 'USD',
            'notes' => fake()->optional()->sentence(),
        ];
    }

    public function pending(): static
    {
        return $this->state(fn () => ['status' => OrderStatus::Pending->value]);
    }

    public function shipped(): static
    {
        return $this->state(fn () => [
            'status' => OrderStatus::Shipped->value,
            'shipped_at' => fake()->dateTimeBetween('-1 week', 'now'),
        ]);
    }
}
```

### Seeders

Use Pest-compatible seeder patterns:

```php
class DatabaseSeeder extends Seeder
{
    public function run(): void
    {
        User::factory()->create([
            'name' => 'Admin User',
            'email' => 'admin@example.com',
        ]);

        User::factory(10)->create()->each(function (User $user) {
            Order::factory()->count(fake()->numberBetween(1, 5))->create([
                'user_id' => $user->id,
            ]);
        });
    }
}
```

### Testing with Factories

```php
it('can list orders', function () {
    $user = User::factory()->create();
    Order::factory()->count(3)->create(['user_id' => $user->id]);
    Order::factory()->create(); // Different user

    $response = $this->actingAs($user)->getJson('/api/v1/orders');

    $response->assertStatus(200)
        ->assertJsonCount(3, 'data');
});
```

## Normalization

Follow standard database normalization:

- **1NF**: All columns contain atomic values; no repeating groups
- **2NF**: All non-key columns fully depend on the primary key
- **3NF**: No transitive dependencies (non-key columns depend only on the key)
- Use pivot tables for many-to-many relationships
- Denormalize intentionally for performance (with documented rationale)

```php
// Many-to-many: users ↔ roles via pivot table
Schema::create('role_user', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->foreignId('role_id')->constrained()->cascadeOnDelete();
    $table->unique(['user_id', 'role_id']);
});
```

## Database Configuration

```env
# .env
DB_CONNECTION=mysql
DB_HOST=127.0.0.1
DB_PORT=3306
DB_DATABASE=app_local
DB_USERNAME=root
DB_PASSWORD=secret

# Queue (Redis)
REDIS_HOST=127.0.0.1
REDIS_PASSWORD=null
REDIS_PORT=6379

# Cache (Redis) — renamed from CACHE_DRIVER in Laravel 11+
CACHE_STORE=redis
```

Use different database names for local, testing, and production environments.
